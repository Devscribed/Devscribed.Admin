14 — Task Collaboration

Static visual target for the task-collaboration surfaces that extend /org/{orgId}/projects/{projectId}/tasks/{taskId} (spec 13's task detail page and Board Settings modal). Covers labels (chip anatomy, task-card display, Board Settings management, the add-label picker), comments (populated thread, composing, inline edit, delete confirmation), watchers (watching / not-watching states), and the activity log. No new route — every state below is a fragment of spec 13's existing pages. Pairs with 14-task-collaboration.md.
