# User Management Specifications

Functional specifications for the user-management surface of Devscribed.Admin. Each spec is a self-contained feature document with its own requirements, UI notes, and test cases.

| # | Spec | Summary |
|---|------|---------|
| 01 | [Organization Creation](01-organization-creation.md) | Signup flow: create account + organization + first admin membership |
| 02 | [Authentication & Login](02-authentication-login.md) | Email/password login, forgot/reset password flows |
| 03 | [User Invitation](03-user-invitation.md) | Invite members by email with role selection, accept flow for new and existing accounts |
| 04 | [Member List & Management](04-member-list-management.md) | Members screen with search, delete/restore, inline role picker |
| 05 | [Member Detail: About](05-member-detail-about.md) | Member detail view with role and job title editing |
| 06 | [Account Settings](06-account-settings.md) | Self-service email change, password change, and profile editing |
