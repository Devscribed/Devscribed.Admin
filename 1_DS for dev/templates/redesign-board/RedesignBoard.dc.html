Design system redesign

Same skeleton, new voice.

Every component, state, and layout rule from Teamplay 2.0 is kept intact — only the visual language changes. Meridian trades the cool, flat, iOS-blue Poppins skin for a warm, editorial system: paper neutrals, an indigo-violet accent, Space Grotesk display + IBM Plex Sans text.

Before After
Preserved
Component set & API · structure & hierarchy · all states (hover / focus / disabled / error) · nav model · calendar & tracker behavior
Changed
Type pairing · palette (cool→warm + violet accent) · corner & border language · shadow feel · badge & active-state treatment · wordmark
NEW DIRECTION Meridian Dark — dark-first

Built for the dark.

Same Meridian bones — warm neutrals inverted into deep charcoal, the violet accent turned up so it glows, amber held back for the one thing that's live: the tracker.
