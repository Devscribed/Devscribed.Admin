# Eye · EyeOff

Filled, geometric glyphs for password reveal. Both inherit `currentColor` and default to the 18px house size — no stroke, no duotone, no icon font.

```jsx
<Eye />
<EyeOff size={16} />
```

`Eye` means "currently masked — click to reveal". `EyeOff` means "currently visible — click to mask".
