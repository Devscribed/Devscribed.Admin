# NavItem

Sidebar navigation row. Active state is violet ink on a violet-soft pill with an accent-border. Hover state is the universal accent tint.

```jsx
<NavItem icon={<TimesheetsIcon/>} label="Timesheets" active />
<NavItem icon={<PeopleIcon/>} label="People" arrow="closed" />
<NavItem label="Requests" badge={3} />
```
