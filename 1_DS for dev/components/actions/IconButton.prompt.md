# IconButton

Borderless square button carrying a single line-free glyph. Hover is the universal `--hover-bg-tint`; `active` tints the glyph violet.

```jsx
<IconButton label="Show password"><Eye /></IconButton>
<IconButton label="Hide password" active><EyeOff /></IconButton>
```

Always pass `label` — the button has no text to name it.
